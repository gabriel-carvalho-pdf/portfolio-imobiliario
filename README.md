# 🎬 Portfólio de Audiovisual Imobiliário com IA

## 📖 Sobre o Projeto
Uma landing page (one-page) estratégica desenvolvida para atuar como portfólio digital na captação orgânica de corretores e imobiliárias. O objetivo do site é apresentar soluções audiovisuais de alto padrão, destacando o uso de Inteligência Artificial para transformar anúncios de imóveis e reter a atenção dos clientes. A estrutura foi pensada para gerar conversão direta via WhatsApp.

## 🚀 Funcionalidades e Diferenciais
- **Performance Extrema (Carregamento Rápido):** Desenvolvido em código puro (sem frameworks pesados), garantindo que a página abra instantaneamente no 4G, ideal para corretores em trânsito.
- **Design Mobile-First:** Interface responsiva construída com Flexbox e CSS Grid, otimizada prioritariamente para leitura e navegação em smartphones.
- **Estética Premium (Dark Mode):** Paleta de cores focada em transmitir exclusividade, alto padrão e inovação tecnológica.
- **Integração de Vídeos Inteligente:** Players de vídeo incorporados de forma assíncrona (YouTube-nocookie) para não comprometer o peso da página e respeitar políticas de privacidade.
- **Call to Action (CTA) sem Fricção:** Botão flutuante de WhatsApp fixo na tela para contato imediato.

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estrutura semântica e acessível.
- **CSS3:** Estilização com variáveis customizadas e layouts fluidos.
- **Deploy/Hospedagem:** GitHub Pages.
